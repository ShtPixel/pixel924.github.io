Mi terre es un sistema de información comunitario pensado para el Municipio de Mallama y pensado para expandirse también a sectores vecinos.
El sistema esta construido con una estrucctura SPA (single page aplication) o mejor dicho una plataforma de una sola pagina con contenido que cambia de manera dinamica.

El proyecto esta construido con la siguiente estructura:

## Estructura

- `index.html`: entrada principal del sitio.
- `resources/html/`: secciones cargadas dinamicamente.
- `resources/css/`: estilos del sitio.
- `resources/js/`: logica de rutas, componentes y paginas.
- `resources/images/`: imagenes locales.
